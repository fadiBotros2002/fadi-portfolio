# Internationalization

## Config

`js/i18n/config.js`:

- `default`: `en`
- `cycle`: `en` → `ar` → `de`
- `locales`: name + `dir` (`ar` = `rtl`)
- JSON path: `assets/i18n/{lang}.json`

## Applying copy

- Static HTML: `data-i18n="dot.path"`; use `data-i18n-html` when the string contains markup.
- JS: `window.I18n.t('dot.path')` or `window.I18n.data.…`
- After language change: `I18n.apply()` then `renderProjects()`.

## Important key groups

```
nav.*                          # no nav.linkedin in the bar (key may linger unused)
hero.*                         # subtitle/description = Backend + Odoo
about.*
experience.asas.*              # current role (ASAS)
experience.freelance.*
experience.samware.*
experience.education.*
skills.g1Title … g6 / gFrontend / gInfra
projects.title | lead
projects.odooTitle | odooLead
projects.softwareTitle | softwareLead
projects.ui.*
projects.items.{id}.*
contact.* | footer.*
```

When adding a locale: new JSON file + entry in `I18N_CONFIG.locales` and `cycle`.

## Persistence

`localStorage.language` and `localStorage.theme` — early init in `index.html` must stay in sync with supported values.
