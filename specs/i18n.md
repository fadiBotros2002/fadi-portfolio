# Internationalization

## Config

`js/i18n/config.js`:

- `default`: `en`
- `cycle`: `en` → `ar` → `de`
- `locales`: name + `dir` (`ar` = `rtl`)
- JSON path: `assets/i18n/{lang}.json`

## Applying copy

- Static HTML: `data-i18n="dot.path"`; use `data-i18n-html` when the string contains markup.
- JS: `window.I18n.t('dot.path')` or `window.I18n.data.…`
- After language change: `I18n.apply()` then `renderProjects()` (projects rebuild from JSON).

## Project keys

```
projects.title
projects.lead
projects.ui.github | featured | wip | minorStudent
projects.items.{id}.title | period | description
projects.items.{id}.links.{labelKey}   # only if catalog rows use that labelKey
```

When adding a locale: new JSON file + entry in `I18N_CONFIG.locales` and `cycle`.

## Persistence

`localStorage.language` and `localStorage.theme` — early init in `index.html` must stay in sync with supported values.
